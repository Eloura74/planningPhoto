## 📅 Gérer les Créneaux en 3 Étapes

### 1️⃣ Créer un Créneau

```
Dashboard Admin → Onglet "📅 Créneaux" → ➕ Nouveau Créneau
```

**Remplir :**
- Date : 15/11/2026
- Début : 14:00
- Fin : 17:00
- Type : SOLO ou GROUPE

**Résultat :** Le créneau apparaît dans la liste ET dans le calendrier ! 🎉

---

### 2️⃣ Modifier un Créneau

```
Liste des créneaux → ✏️ Modifier
```

**Vous pouvez changer :**
- La date
- Les horaires
- Le type (SOLO ↔ GROUPE)

**Résultat :** Tout se met à jour automatiquement !

---

### 3️⃣ Convertir SOLO ↔ GROUPE

**Méthode rapide :**
- Cliquez sur **🟢** (vert) → Convertir en SOLO (14h-17h)
- Cliquez sur **🟠** (orange) → Convertir en GROUPE (10h-17h)

**Résultat :** Le type ET les horaires changent automatiquement !

---

## 🎨 Codes Couleur

| Couleur | Signification |
|---------|---------------|
| 🟢 Vert | Disponible solo |
| 🟠 Orange | Disponible groupe |
| 🟣 Violet | Confirmé |
| 🔴 Rouge | Demandes en attente |
| ⚫ Gris | Complet |

## 🚀 Navigation Rapide

### Cartes Cliquables du Dashboard

1. **👥 Utilisateurs** → Page gestion utilisateurs
2. **📅 Créneaux** → Onglet gestion créneaux
3. **⏳ En attente** → Scroll vers réservations
4. **👨‍👩‍👧‍👦 Pré-réservations** → Scroll vers réservations

---

## 💡 Cas d'Usage Rapides

### Ouvrir un dimanche en solo
```
Créneaux → Nouveau → Dimanche 20/11 → SOLO → 14h-17h → Créer
```

### Bloquer un mercredi pour un groupe
```
Créneaux → Nouveau → Mercredi 25/11 → GROUPE → 10h-17h → Créer
```

### Passer un créneau de solo à groupe
```
Liste → 🟠 Orange à côté du créneau → Confirmer
```

## ⚠️ Important

- **Rechargez la page** (`Ctrl + Shift + R`) pour voir les changements
- **Les stats se rafraîchissent** automatiquement toutes les 10 secondes
